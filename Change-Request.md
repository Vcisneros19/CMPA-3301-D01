# Project Change

## Proposed Change

The proposed change is to add an embedded Google Map to my Midterm Project website showing my hometown of Dallas, Texas. The map would be added to one of the pages and allow
users to see the location directly from the website without having to open another page.

## Reasons for the Change

The instructor might want this change to make the website more interactive and add more information about me. Since the website is a personal project, showing my hometown
gives visitors a little more background about where I am from. It would also give me more experience adding outside features into an HTML website.

## How This Change Will Add Value

Adding a Google Map would make the website more useful and interactive. Instead of only reading information about my hometown, visitors would be able to actually see the location
on a map. It can also make the website feel more complete and give it another visual element.

## How This Change Will Affect the Constraints

* Time: The change would require minimal to mid additional time to learn how to embed a Google Map and make sure it displays correctly on the website. I would also need time to test it
   before submitting the project.

* Quality: This change could improve the quality of the website by making it more interactive. However, I would need to make sure the map fits correctly with the rest of the map and 
the quality would be mid due to the timing I use.

* Budget: There should be little to no effect on the budget because embedding a basic Google Map can be done without purchasing additional software or services.
