#Project 03 - Project Scope Statement

##Personal Portfolio Website

###Project Purpose

The purpose of this project is to create a simple personal portfolio website that introduces who I am, my education, skills, and some of the projects I have worked on. I want to create something that can be used for this class but also something that could be useful for me in the future when applying for jobs or internships.

This project will also help me practice HTML, CSS, GitHub, and the project management skills I have learned throughout this course.

Project Description

For this project, I will create a two-page personal portfolio website using HTML and CSS. The website will have a homepage and an about page. The homepage will introduce me, my career interests, skills, and give visitors a quick idea of what my portfolio is about. This portfolio is meant to help me organize and guide me through my projects.

The about page will include more information about my education, experience, goals, and interests. Both pages will use the same CSS file so the design stays consistent.

Desired Results

By the end of the project, I want to have a working and professional looking website that is easy to navigate and represents me. The website should work correctly through GitHub Pages and both pages should be connected.

I also want the GitHub repository to be organized and easy to understand. Someone looking at the repository should be able to understand the purpose of the project and see the planning that went into it.

Project Deliverables

A public GitHub repository

A professional README.md file

An index.html homepage

An about.html page

One style.css file used by both pages

A docs folder containing scope.md, plan.md, and retrospective.md

A working website published through GitHub Pages

Project Requirements

The website will have at least two working HTML pages that are linked together. Both pages will use one external CSS stylesheet to keep the design consistent. The website should have a clean layout that is easy to read and navigate.

The GitHub repository will contain all website files and project documentation. I will also use GitHub throughout the project to keep track of changes and previous versions of my work.

Exclusions

This project will not include advanced features such as user accounts, databases, online payments, or complicated JavaScript.

Project Constraints

One of my biggest constraints will be time because I have to balance this project with my other classes and work. Because of this, I want to keep the website simple enough that I can complete everything on time while still making it look professional. I am also still new to HTML and CSS, so that can be another challenge throughout the project.

Project Success Criteria

I will consider this project successful if the website has two complete pages, both pages are linked correctly, and the CSS works consistently across the website. The GitHub Pages link should also work without any errors.

The repository should contain all required files and documentation, and someone visiting the repository should be able to easily understand what the project is about.
